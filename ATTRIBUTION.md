# Sources and provenance

The skill, Python helper, layout, tests and agent-authored notes were newly created for this public conference preparation tool. No personal or internal workflow, private repository, connected work document, installed plugin resource, account integration or private input was copied into this project.

Programme facts, talk titles, abstracts, speakers and links are from FOSDEM and the named speakers:

- [FOSDEM 2026 schedule](https://archive.fosdem.org/2026/schedule/), [XML](https://archive.fosdem.org/2026/schedule/xml). The website footer states [CC BY 4.0 International](https://creativecommons.org/licenses/by/4.0/).
- [FOSDEM 2025 schedule](https://archive.fosdem.org/2025/schedule/), [XML](https://archive.fosdem.org/2025/schedule/xml). The website footer states [CC BY 2.0 Belgium](https://creativecommons.org/licenses/by/2.0/be/).

The full public exports were retrieved on 28 October 2026. Included JSON catalogs convert HTML abstracts/descriptions to plain text and retain stable IDs, scheduling facts and published links. Selected excerpts appear alongside new goal-specific commentary and questions. Every selected session names its speakers and links to its official page. No conference or speaker endorsement is implied. The programme material retains its source license; the MIT license applies to the new code, skill, layout and authored commentary.

Public needs and existing approaches informed the independently created workflow:

- The [official 2026 overview](https://archive.fosdem.org/2026/schedule/) describes 1,079 events across 71 tracks and publishes raw schedule data.
- The [official mobile application list](https://archive.fosdem.org/2026/schedule/mobile/) already supplies schedule browsers, favourites and calendar-oriented tools. Conference Desk adds attendee-goal interpretation and finished preparation, rather than claiming schedule browsing is new.
- The [Local-First devroom's practical information](https://openlocalfirst.org/blog/practical-devroom/) describes room-capacity and movement constraints. The tool's 15-minute room-change default is an editable assumption, not a quoted FOSDEM-wide rule or verified route estimate.
- [pretalx scheduling documentation](https://docs.pretalx.org/user/schedule/) explains released schedule snapshots and changes, informing the explicit refresh boundary.

The synthetic attendee briefs are invented scenarios. Programme dates remain historical. The current agent session created both complete assessments; no attendance, use by real attendees, separate host trial or measured time saving is claimed.
